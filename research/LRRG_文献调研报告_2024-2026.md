# DDaTR 复现创新点调研报告：2024–2026 纵向放射报告生成（LRRG）文献全景

> 报告日期：基于多轮 web_search（≥10 轮）+ 逐篇 arXiv/OpenReview/出版社页面细读整理。
> 面向目标：找出能显著提升 **MIMIC-CXR 与 Longitudinal-MIMIC 上 CheXbert CE F1 与 BLEU/METEOR/ROUGE**、且尚未被做过的创新点。
> 核心基准：DDaTR（IEEE TMI 2025, arXiv:2505.03401, xmed-lab）。

---

## 0. 先读这页：三个决定创新点价值的"事实"

### 0.1 必须区分两套评估协议（否则对比全是错的）
LRRG 领域存在两套互不通用的 CE F1 报告习惯：

| 协议 | 数据集/切分 | CE F1 口径 | 谁在用 |
|---|---|---|---|
| **MIMIC-CXR 全测试集**（RECAP 协议） | 3,858 个 test 样本（含无先验的首诊），Findings 段 | **Macro** F1 | RECAP、DDaTR、HERGen、EVOKE、MLRG 等 |
| **Longitudinal-MIMIC**（ULCX/LR2Gen 协议） | 2,058 个 test 样本（266 patients，仅≥2 次就诊者），Findings 段 | **Micro** F1 | DDaTR、HC-LLM、BiOTPrompt、ULCX、Diff-RRG |
| MLLM 家族自建 frontal-only 切分（Libra/RADAR/MAIRA-2 类） | 2,461 frontal pairs 等 | Macro 或 micro，各自为政 | Libra、RADAR、MAIRA-2、STREAM |

- **DDaTR 论文自己的数字**：MIMIC-CXR macro F1 = **0.441**（P 0.438 / R 0.465，+0.048 vs PromptMRG 0.389）；Longitudinal-MIMIC micro F1 = **0.527**（P 0.539 / R 0.584，+0.023 vs vanilla 0.504）；NLG：BLEU-4 0.113 / METEOR 0.162 / ROUGE-L 0.272（MIMIC-CXR），BLEU-4 0.105 / METEOR 0.156 / ROUGE 0.266（Long-MIMIC）。
- **所以"对标 DDaTR"的正确姿势**：想超越必须同时报两套协议（DDaTR 的 SOTA 是靠两套协议双高撑起来的）。

### 0.2 领域公认的五个死穴（2025.10 综述 arXiv:2510.12444 第 7 节逐条列出）
1. **先验-当前图像未配准**（体位/视角不一 → 同名解剖落到不同 patch，像素差被污染）—— 综述点名"迄今没有任何 LRRG 方法做配准"；
2. **时间间隔几乎没人建模**——只有 TiBiX（粗粒度间隔 token）与 HERGen（time vocabulary）做浅层编码，且均不做"间隔↔差特征"的联动；
3. **多先验冗余**——全部历史拼接引入冗余/噪声，HIST-AID 平均 11 先验只是暴力送入，没有"先验选择/时间路由"；
4. **纵向专用评估缺失**——GREEN/TEMPORALGROUP/RGER 等还不够；LLM 标注基准刚出现（arXiv:2601.16753）；
5. **纵向数据本身稀缺**——Long-MIMIC 只有 2,058 测试样本，大部分方法靠"同一病人重采样扩增"，偏置短间隔变化。

### 0.3 "Recall 是 CE F1 的最短板"是**有数据支撑的领域级结论**
- A. 综述 Table 3（CE 指标）逐模型看：HC-LLM R 0.357 < P 0.417；BiOTPrompt R 0.424 < P 0.471；MLRG R 0.354 < P 0.440；STREAM R 0.447 < P 0.515；EVOKE R 0.350 < P 0.400；R2GenGPT 家族 R 普遍远低于 P。
- B. DDaTR 自己的消融（其 Table 22）：去掉动态融合（w/o DF）后 MIMIC-CXR **precision 0.402→0.438（+0.036）而 recall 0.465 纹丝不动**；Long-MIMIC 上 recall 仅 0.583→0.584。→ **"动态融合只买 precision，不买 recall" 是 DDaTR 论文自己的消融结论**。
- C. 最新头部工作的亲口承认：CXRMate-2（2026-04，arXiv:2604.18967）的放射科医生盲评结论——"**Improving recall and the detection of subtle findings represents the primary remaining barrier** to non-inferiority with radiologist reporting"。

**推论：任何能把 recall 拉起来的创新（而不只卷 precision）都是 CE F1 的直接增量，且这个增量方向整个 2024-2026 都没有专门论文。**

## 1. 2024–2026 LRRG 论文清单与一句话方法总结（附链接）

### 1.1 直接对标 DDaTR 的后续/同期头部工作（按时间）

| 论文 | 出处/arXiv | 一句话方法 | 与 DDaTR 的关系 |
|---|---|---|---|
| **BiOTPrompt** | CVPR 2026（Tengfei Liu 等，OpenAccess） | 先验↔当前图像做**双向最优传输（BiOT）**，用双向传输计划的不对称性定位"新出现/消退区域"，构造动态 prompt 引导 LLAMA2-7B 解码；加视觉-语言一致性约束抑幻觉 | 其 Long-MIMIC 对比集内 SOTA（macro F1 0.417、BLEU-4 0.126，全面超 R2GenGPT 系/Prefilling/HERGen/HC-LLM）；**注意：其对比表未含 DDaTR，且报 macro 而 DDaTR 在 Long-MIMIC 报 micro(0.527)，口径不可直接比**；只用了 prior **图像**不用报告，是 R2GenGPT/LLM 家族，与 DDaTR 架构不同 |
| **Diff-RRG** | MICCAI 2025（Yun 等） | 用 BiomedCLIP 对先验/当前图像做**逐疾病 patch 级差分**，把"疾病维度的 patch 差异"当 prompt 喂给 BioMistral | 与 DDaTR 的 DDAM"像素差"同一路线，但上移到 patch/疾病粒度 + LLM 解码；Long-MIMIC F1_micro 0.474 < DDaTR 0.527，NLG 略高 |
| **Transition-Aware best-of-N** | arXiv:2606.28393 | **首个 training-free 的纵向感知 best-of-N 采样**：把(先验,当前)对压成"方向向量"，与训练真值的过渡向量库做余弦匹配选候选句子；四个方向距离（mean-shift / novelty residual / directed-Hausdorff / cost-weighted OT） | 纯解码端后处理，不训练模型；在 AP-PA（ImaGenome 类）队列上 3 个生成器 × 3 prompts 验证，Impression 段增益最大——**可无缝叠加在任何生成器上（含 DDaTR）** |
| **CXRMate-2** | arXiv:2604.18967（CSIRO AEHRC） | 结构化多模态时序嵌入 + 高分辨率视觉压缩 + **GRPO（group-relative policy optimization）**统一条件化 LLM；MIMIC-CXR 上 GREEN +11.2%、RadGraph-XL +24.4%（vs MedGemma 1.5 4B）；放射科盲评 45% 可接受 | 单图为主 + prior 文本；证明 **RL/语义奖励可以同时拉多项临床指标**，但**作者明确说 recall 仍是主要缺口** |
| **LEAD** | arXiv:2602.04617 | 多专家（病理特征）按层门控注入 LLM 每层解码，动态矫正 decoding bias 抑幻觉 | 与 DDaTR 的"stage 级门控融合"同构但放在解码端；单图为主 |
| **MRG-R1** | arXiv:2512.16145 | **报告级语义 RL（SRL）**：奖励直接对齐"临床相关发现"的语义而非 token 似然，IU-Xray/MIMIC-CXR 临床效能 SOTA | 单图任务，但方法论可搬到纵向（见 §5 方向 C） |
| **CLARIFID** | arXiv:2507.17234 | 双段工作流：段级预训练(F→I) + **PPO 用 Impression 的 CheXbert F1 当奖励** + 受控解码（先 Findings 后 Impression）+ 多视图融合 + next-token forcing/re-rank | 单图+多视图；"**用 CE F1 本身当 RL 奖励**"的直接先例 |
| **MLRG**（=用户所提 CVPR 2025 Enhanced Contrastive Learning） | CVPR 2025，arXiv:2502.20056 | 多视图(正侧位)×纵向(最近两次先验)的**batch 级跨模态对比学习**预训练 + **tokenized absence encoding**（缺失先验的软处理）；RAD-DINO + DistilGPT2 | 多先验(+2) + 缺失处理 + 对比学习三件套；MIMIC-CXR BLEU-4 0.158、F1_macro 0.364 / micro 0.505 |
| **RADAR** | ACL 2025，arXiv:2505.14318 | 把 LLM **内部已有知识**（与专家图像分类对齐提取）+ **外部检索补充知识**聚合后再生成（SigLIP+Phi3-mini） | frontal-only 自建协议 F1_macro 0.460/0.653（协议不可直接比 DDaTR） |

## 3. 已经被做过的方向（⚠️ 撞车清单）

| 技术方向 | 已做论文 | 结论 |
|---|---|---|
| 像素/特征差分显式建模 | DDaTR(DDAM)、BiOTPrompt(双向OT差)、Diff-RRG(疾病维patch差)、Libra(TAC时间差)、ALTER(3D CT区域差)、EVOKE(时间差自注意力) | **"做差分"本身已拥挤**；差异点在粒度（像素/特征/疾病维/区域）与方向（单向/双向） |
| 动态门控融合 | DDaTR(门控+残差)、HC-LLM(共享/特有门控)、DECKS 类 CSS 门控 | 已有；但都是"融合权重"，不是"配准" |
| 进展/变化分类中途监督 | RECAP(progressions classifier)、TiBiX(时序分类)、HERGen(disease progression 预测)、HC-LLM(变化方向判断较弱) | 已有，但**没有专门监督"definitive vs probable"程度** |
| 跨模态/跨时间对比学习 | BioViL-T、RECAP、MLRG(batch级)、PriorRG、HC-LLM(患者级+几何一致)、EVOKE | 很拥挤；MLRG 已证明对比学习对 CE F1 是**决定性组件**（去掉后 F1 0.497→0.373） |
| 多先验（>1 个） | HERGen(≤5)、EVOKE/MLRG/STREAM(2)、HIST-AID(≈11) | 已有；但"时间路由/选择哪些先验"没有精细做法 |
| 时间间隔编码 | TiBiX(token)、HERGen(time vocabulary) | 只有 2 篇且都是浅层编码；**"间隔感知的差特征调制"没人做** |
| 多视图融合 | MLRG、MAIRA-2、CXRMate、EVOKE、STREAM | 拥挤 |
| RL/语义奖励 | CXRMate(CXR-BERT reward)、CXRMate-2(GRPO)、MRG-R1(SRL)、CLARIFID(PPO+CheXbert F1)、CURV(RL) | 已有，且 CLARIFID 证明"CE F1 当奖励"有效；**但全部不是纵向的，且 RL 没直接修 recall** |
| 检索/知识注入 | RADAR(内外部知识)、RECAP(关系图)、KiUT、MAIRA-2(grounding) | 已有 |
| 缺失先验处理 | zero-padding、CLS-token、Libra 可学 bias、LDSSR pseudo prior、CXRMate 无 prior 可用、MLRG tokenized absence encoding | 已很全面 |
| 不确定度建模 | CURV(NeurIPS 2025)、Semantic-Consistency UQ、NeuroSymb-MRG、Uncertainty Encoding | **都是单图 RRG**；纵向+不确定度 = 空白 |
| 训练-free 解码采样 | Transition-Aware best-of-N（2026） | 刚出现 1 篇；"差分感知采样"刚开题 |
| 纵向专用评估 | GREEN、TEMPORALGROUP、RGER/RadCliQ、LLM标注基准(2601.16753) | 评估侧正在成型 |

## 4. 明显还没人做的方向（＝创新空白，按"对 CE F1 的杠杆"排序）

### 空白 A：解剖配准后的差分解码（空间对齐 × 差分）
- **现状**：没有任何 CXR LRRG 论文做先验-当前配准。DDaTR 的 DDAM 直接在未对齐特征上做 LDConv+像素差——体位/视角差异直接进差特征；综述 7.1.4 明确点名这是没解的问题（同一病人肺部区域跨时间可能位移 1 个 patch 以上；正面/侧面混合时更严重）。
- **可落地点**：肺野可形变配准（Diffeomorphic / VoxelMorph 类，或 BiOT 软对齐）作为 DDAM 的**前置归一化**：① 配准场监督（肺野分割对齐、landmark 一致性）；② 差特征在**配准后的坐标系**里算，天然滤掉体位噪声 → precision 更准；③ 配准场本身是新的临床信号（如肺容积变化率）。
- **为什么没人做**：CXR 配准在别的领域（影像组学）成熟但从未接入 LRRG 的端到端；BiOTPrompt 用 OT 软对齐但只用来找"新出现/消退区域"，未做解剖一致性约束。
- **预期杠杆**：直接修 DDaTR 的已知病灶（"先验/当前图像未做解剖配准导致像素差被污染"），precision + recall 双升机会大。

### 空白 B：时间间隔感知的差特征调制（interval-conditioned difference）
- **现状**：TiBiX 间隔 token、HERGen time vocabulary 都只是"把间隔塞进输入"。**没有任何工作把间隔编码成条件去调制差分强度/门控**——而临床常识：间隔 2 天 vs 间隔 2 年，同样的像素差含义完全不同（短期=恶化/好转管理，长期=慢性演变）。
- **可落地点**：在 DDaTR 的 DDAM 门控里加连续时间条件：`F_diff' = gate(Δt, Δt_emb) ⊙ F_diff`；或者把 Δt 回归加入先验分类头做辅助监督（"间隔→进展类别"先验）。甚至可结合"不规则间隔"(MICCAI 2025 扩散模型思想)。
- **为什么没人做**：综述 7.1.2 明确"only a few explicitly consider time gaps…and none align time gaps with patient-specific context"。
- **预期杠杆**：中等-高；对"复发-缓解型"(胸腔积液/水肿)与"长期稳定"语句的 BLEU/ROUGE 与 CE 都有帮助；是个**低成本、高辨识度**的增量。

### 空白 C：recall 导向 / 完整性导向的训练目标（CE F1 的命门）
- **现状**：领域所有方法 recall 普遍 < precision；DDaTR 消融证明动态融合不动 recall；CXRMate-2 放射科盲评宣布"recall 是主要剩余障碍"；但 2024-2026 **没有任何 LRRG 论文把"提升 recall"作为主目标**（MRG-R1/CLARIFID 的 RL 奖励是报告级语义/Impression-CE，且单图）。
- **可落地点**（按可实现性排序）：
  1. **标签重加权/焦点损失**：DDaTR 已有当前+先验双分类头，把 CE loss 换成 CheXpert 类别加权 focal loss（长尾、罕见发现 recall 低）；
  2. **覆盖率奖励/RL**：解码时给"先验报告提到的发现是否被当前报告提及"加覆盖奖励（先验→当前的一致性），可直接对标 CXRMate-2 的结论；
  3. **先验驱动的补全解码**：如果当前图像编码器"漏报"某发现（先验有、当前有），用先验-当前差分激活做"提示补全"（和 BiOTPrompt 的"新出现区域 prompt"互补）；
  4. 评测侧配套：用 2601.16753 的 LLM 标注做"纵向发现遗漏率"自有指标。
- **为什么没人做**：CE-F1 评测是 macro/micro 平均，多数人优化 precision（避免乱报）；没人专门针对 recall 的缺失代价建模。
- **预期杠杆**：**直接对应 CE F1 数值**——在 DDaTR 基线（0.441 macro / 0.527 micro）上，recall 每涨 2-3 点就是 F1 +1.5-2 点，且这是目前"被公认但没人动手"的空档。

### 空白 D：纵向不确定性建模（definitive / probable 程度 + 校准）
- **现状**：CURV(NeurIPS 2025) 做了置信度表达与推理链，但**单图**；DDaTR 的 [BLA]/[POS]/[NEG]/[UNC] prompt 只教"是/否/不确定"三类，不建模程度（"likely/probably/definitive"）、不做输出校准；[UNC] 的预测质量没人验证。
- **可落地点**：① 把不确定度词扩展为程度分级并给**放射学专家级标注**（可利用 CheXpert 的 uncertain 标签）；② 预测-校准损失（把分类头的 logit 校准到"报告里 hedge 词出现概率"）；③ 纵向特有：**进展方向的不确定度**（"可能改善 vs 稳定 vs 恶化"）+ 间隔交互（短间隔高不确定）。
- **为什么没人做**：评估指标（BLEU/CE）不奖励 hedge 词，历来被忽略；但 RadCliQ/GREEN/放射科可用性评估会奖励。
- **预期杠杆**：中等；差异化亮点 + 临床可用性（TMI 审稿人会喜欢），对 CE F1 的直接收益偏间接。

### 空白 E：多先验时间路由 / 先验选择（把"用哪个先验"变成可学习决策）
- **现状**：HERGen/HIST-AID 暴力多先验；HIST-AID 自己发现"最近先验最有用、旧先验可能误导"——**这正是一个可学习路由的机会**，但没人做成可微选择。
- **可落地点**：先验序列编码 + 时间注意力路由（对每个先验打分，软选 top-k 或门控加权），配合间隔与"是否同视角/同体位"作路由特征；同时做 token 冗余剪枝（综述建议）。
- **预期杠杆**：中等；能把"HIST-AID 的观察"变成方法，且在 Long-MIMIC 上（测试集全是≥2 次就诊）直接有效。

### 空白 F（配套）：纵向专用评估基准（作为任何方法的"讲故事"抓手）
- LLM 标注基准刚出现（2601.16753）；GREEN/TEMPORALGROUP 未大规模放射科验证。**若你的方法顺手报"纵向遗漏率/幻觉先验率"（GREEN e/f 项），评审说服力会强很多**——这是低成本高回报的配套动作，不是主创新。

## 5. 判断：DDaTR 之后最有希望显著提升 CE F1 的 3–5 个空白方向（纯文献角度）

> 排序依据：① 直接命中 CE F1 的分母（recall/precision 的哪个分量）；② 是否已有论文抢占；③ 实现成本/与 DDaTR 架构的兼容度；④ 审稿辨识度。

**第 1 名：配准感知的差分解码（空白 A）**——DDaTR 已知病灶（"像素差被体位污染"）是它最容易被攻击的点，配准前置是"修补 + 超越"的最直接叙事；BiOTPrompt(OT) 已证明"软对齐+差分"能拿 Long-MIMIC SOTA，你还有"刚性/可形变配准 + 解剖约束 + 配准场作为新信号"的完整空地，且能同时解释 precision（更准的差特征）与 recall（多视角一致性找回漏报）。

**第 2 名：recall 导向训练；与 RL/覆盖率奖励或 focal-loss 结合（空白 C）**——整个领域公认的短板 + CXRMate-2/MRG-R1/CLARIFID 已证明"报告级临床奖励"可行但没人纵向化。这是**确定性最高、数字上最可预期**的 CE F1 增幅（在 DDaTR 0.441/0.527 基线上，recall 是唯一还有肉的分量——precision 已被一堆 gate 卷到 0.44-0.47）。

**第 3 名：时间间隔感知的差特征调制（空白 B）**——TiBiX/HERGen 只做到"输入编码"，"间隔↔差分门控/进展监督"是真空；实现成本低，能直接塞进 DDaTR 的 DDAM（一个 interval embedding + 门控），且在"复发-缓解"型发现上同时提升 NLG（比较句/稳定句）与 CE。

**第 4 名（差异化备选）：多先验时间路由（空白 E）**——HIST-AID 的观察（最近先验最有用）给了你免费的 motivation；Long-MIMIC 测试集全部 ≥2 次就诊，路由在测试分布上直接获益；可与第 3 名合并成"时间轴路由+间隔调制"的完整 story。

**第 5 名（墙内开花）：纵向不确定度（空白 D）**——对 CE F1 的直接杠杆最小，但对 TMI/MedIA 的"临床价值"叙事与 RadCliQ/GREEN 指标、以及"definitive vs probable"（你点名的 DDaTR 弱点）是唯一对症的方向；适合作为主创新的辅助模块。

**不建议撞的车**：纯差分建模（DDaTR/BiOTPrompt/Diff-RRG/ALTER 已占满）、多视图×对比学习（MLRG 已占）、先验缺失处理（已到 tokenized absence encoding 的程度）、检索增强（RADAR/RECAP 已占）。
