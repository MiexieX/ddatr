# 最终投稿方案（问题驱动版）：ProgressPlan

> 2026-09-03 ｜ 原则：**先证明"问题存在且有证据"，再提出为解决问题而生的创新点，最后用实验证明问题被解决。** 不是堆模块。
> 方案主线：纵向报告的核心价值 = **准确描述变化（进展）**。当前模型在"写变化"这件事上存在四个具体、可证明、可量化的缺陷。

---

## 0. 论文叙事（一句话）

> 放射科医生写纵向报告时，最重要的劳动是**描述两次检查之间的变化**（数据实测：87.5% 的纵向对照含新发/消退事件）。但现有纵向报告生成模型在这件事上系统性失败：**看不见要写的变化（P1）、把摆位当变化（P2）、把 1 天当 1 年（P3）、写不出医生的进展句式（P4）**。我们提出 ProgressPlan——用"进展事件表征 → 进展句规划 → 对齐定时定序生成"解决这四个问题。

---

## 1. 问题清单（每个问题 = 证据 + 成因 + 创新点 + 验证设计）

### 问题 P1：模型"看不见要写的变化"——进展事件没有显式表征与监督
**证据链**：
- 数据实测：训练集标签对中 **new 8.91% / resolved 8.58%**；87.5% 纵向 study 对含 ≥1 个进展事件 → 进展是任务核心而非边角；
- DDaTR 论文自己的消融（Tab III）：去掉动态融合 w/o DF 时 **recall 纹丝不动（0.465→0.465）**——差分支只买 precision，**对"新出现异常"的召回没有贡献**；
- DDaTR 论文 case study 自认：漏报进展（Case B 无法区分 definite/probable；Case C 幻觉）；
- 领域级结论：所有 LRRG 模型 recall<precision；CXRMate-2 放射科盲评"recall 是主要剩余障碍"；
- **成因**：DDAM 产出无监督的差标量，没有"进展事件"（新发/消退/加重/好转）表征；解码器不知道要写哪些变化、按什么顺序写；LM 损失不区分进展句与普通句。
**创新点**：① **M3 进展事件监督**——由先验/当前 CheXbert 标签自动构造 14×3 进展三元组（UNC-free 硬目标 / UNC 参与软目标），ProgressHead 监督 + 软进展门控 + recall 加权 focal；② **C1 进展句规划**——反用评估基准 arXiv:2601.16753 的 95k LLM 进展句标注训练"进展句定位器"，输出"本次要写进展句的发现清单"，主题槽按 新发/加重 > 消退/好转 > 稳定阳性 > 阴性 排序；③ **C2 跨模态差分一致性**——约束"图像差分 ≈ 报告差分"（共享空间循环对齐），让差分支学出"可写进句子"的语义。
**验证设计**：进展子集指标（2601.16753 定位的进展句 vs 非进展句分别算 BLEU/CE）；"有事件 vs 无事件"分桶 CE；M3/C1/C2 逐个消融。

### 问题 P2：模型"把摆位当进展"——差分语义被体位/视角污染
**证据链**：
- LRRG 综述（arXiv:2510.12444 §7.1.4）点名：**迄今没有任何 LRRG 方法做先验-当前配准**；
- 代码实读：`FeatureFusion` 的差特征 = LDConv 后 **通道维全局池化标量**（`AvgPool→Sigmoid`），AP/侧位/呼吸相差异会整体污染差值——同一解剖在不同 patch，通道统计被体位主导；
- 数据实测：先验与当前常为**不同视角**（ViewPosition 混合 PA/AP/侧位），且间隔 p10=1（同日多视角复查常见）。
**成因**：DDAM 在未对齐特征上直接算差。
**创新点**：**M1 形变配准**——编码器前置轻量 RegNet（28×28 形变场 + STN warp，~5M 参数），只 warp 先验图到当前坐标系再进 DDAM；自监督 NCC + 平滑正则，零标注；（可选）**C5 解剖掩码门控**进一步把差分限定在肺野/心脏区。
**验证设计**：**按"先验/当前同视角 vs 异视角"分层测试 CE/BLEU**（数据现成可分层——这是 P2 存在性的直接证据图）；配准场可视化；消融 w/wo warp。

### 问题 P3：模型"把 1 天当 1 年"——检查间隔语义完全缺失
**证据链**：
- 数据实测：先验-当前间隔 **1 → 50,001**（中位 114，p25=6，p90=10,796），极度偏斜——同日复查与数年随访并存的真实分布；
- 综述 §7.1.2：只有浅层"间隔进输入"编码（TiBiX token / HERGen time vocabulary），**无人做"间隔→差分门控/进展监督"联动**；
- 临床常识：同一像素差在间隔 1 天（急性管理）与间隔 2 年（慢性演变）下医学含义完全不同。
**成因**：DDaTR 输入中没有任何时间信息，差分增益与进展判断与时间无关。
**创新点**：**M2 间隔条件化门控**——Δt（log 压缩 MLP 嵌入）调制 DFAM/DDAM 门控与进展监督权重（短间隔抑制伪变化、长间隔放大真实演变），并作为 M3 事件监督的置信度先验。
**验证设计**：**按间隔分桶（<7 / 7-30 / 30-180 / 180-365 / >365 天）分层 CE/BLEU**——现在就能用复现模型跑出的"问题证据曲线"；消融 w/wo 间隔调制。

### 问题 P4：模型"写不出医生的句子"——词面质量与对比句式匮乏
**证据链**：
- 复现实测：MIMIC test BLEU-4 0.1099 / METEOR 0.1596 / ROUGE-L 0.2700（论文 0.113/0.162/0.272）——词面指标是纵向赛道最低档（LLM 系 0.14-0.26）；
- 成因：BERT 解码器 + 无结构规划 + 解码参数未调优（beam=3、无 length_penalty、rep_penalty=1.0）。
**创新点**：① **解码升级**（零训练）：length_penalty≈1.5-2.0、beam 4-5、rep_penalty 1.05、Transition-Aware best-of-N 免训练采样、C3 变化模式范例检索注入；② **档B**：TinyLlama-1.1B QLoRA 解码器（HF 缓存已备）。
**验证设计**：W1 先跑零训练解码网格（一两天出数）；档B 在论文冲刺阶段决定是否启用。

## 2. 框架图（问题→机制→实验 一一对应）

| 问题 | 创新机制（模块） | 验证实验（指标） |
|---|---|---|
| P1 看不见变化 | M3 进展事件监督 + C1 进展句规划/主题槽 + C2 差分一致性 | 进展句子集指标、有/无事件分桶、recall |
| P2 摆位当变化 | M1 形变配准（+C5 解剖掩码） | 同/异视角分层、配准场可视化 |
| P3 1天当1年 | M2 间隔条件化门控 | 间隔分桶曲线 |
| P4 写不出句式 | 解码升级 + C3 检索 +（档B LLM） | BLEU/METEOR/ROUGE 网格 |

```
编码端:  M1 配准 ├→ stage×4 (DFAM + DDAM)
                │      ▲ M2 间隔调制门控
                │      ▲ M3 软进展门控 + C2 差分一致性损失
   （进展事件监督 → ProgressHead + 进展句定位器）
                ▼
规划端:  C1 主题槽规划 = 排序(新发/加重>消退>稳定>阴性) × 解剖 × 间隔 × 进展词表
                ▼
生成端:  诊断prompt + 槽序列 + 先验报告 → BERT解码器（档A）/ TinyLlama QLoRA（档B）
         + 解码升级 + C3 变化范例检索 + best-of-N
```
